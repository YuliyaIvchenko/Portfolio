# Данные сервиса «Яндекс Книги» и интернет-магазина BitMotion Kit
[.ipynb](https://github.com/YuliyaIvchenko/Portfolio/blob/main/project3/project3.ipynb)

## Описание проекта 
Неоюходимо провести анализ и рассчитать ключевые метрики активности пользователей сервиса Яндекс Книги. Цель — глубже понять поведение пользователей и найти примечательные закономерности. Эти расчёты помогут понять, как пользователи взаимодействуют с платформой, какие виды контента наиболее популярны, а также выявить особенности поведения пользователей.

Проверить гипотезу о том, что с новым интерфейом интернет-магазина BitMotion Kit  увеличится конверсия покупок, для этого загрузить данные, оценить корректность проведения теста, рассчитать параметры теста, оценить корректность его проведения и проанализировать результаты эксперимента.

## Выводы
Для Яндекс Книг:

Средняя активность пользователей в часах в двух группах (Москва и Санкт-Петербург) не различается.
Возможные причины, объясняющие полученные результаты: возможно, у пользователей в Москве и Санкт-Петербурге сходжий характер к прослушиванию Яндекс Книг, возможно, размер выборок недостаточно велик, чтобы обнаружить небольшие различия в средней активности пользователей, если они всё же присутствуют. 

Для интернет-магазина BitMotion Kit:
Интерфейс онлайн-магазина стал понятнее для пользователей, внедрять новый интерфейс стоит, и это подтверждено тестом.
